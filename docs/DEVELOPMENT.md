# Little Planet · 口袋里的冒险

基于提供的截图，用 Three.js 制作的低多边形小星球网页游戏。场景、建筑、植被、角色和动物均由代码构建；这是参考图风格与玩法的复刻版本，不是原站源码。

## V3 · 邻居与友谊徽章

七个区域现在各住着一位原创动物邻居。3D 角色会呼吸、眨眼、转身看向旅人、招手，并在收到友谊时冒出小爱心。

### 和邻居聊聊天

- 靠近 NPC 后按 **E**，或点击屏幕上的聊天按钮。也可点击人物或头顶的气泡，旅人会走近并开始交谈。
- 对话配有专属头像、名字标签、逐字显示和回应选项。点击文字或按 **E / 空格**继续；文字尚未显示完时，先显示整句话。
- 用鼠标或触屏选择回应，也可按 **1 / 2 / 3** 或方向键、回车选择。
- **完整完成首次对话后**，获得这位邻居的专属徽章。中途关闭、快速旅行或仅仅见面，都不会提前发放徽章。
- 再次拜访时，邻居会记得你的第一次回答，并轮换自己的日常故事。已获得的徽章不会重复计数。
- 按 **B** 打开「一口袋好朋友」邻居簿：查看七枚徽章、收集状态，或选择一位邻居去拜访。触屏可上下滑动浏览。
- 附近同时有 NPC 和景物时，**E 优先聊天，F 执行另一项景物互动**；也可以点击较小的第二个互动按钮。
- **Esc / 右上角关闭按钮**：暂别。对话期间暂停角色移动与镜头操作，不暂停环境里的小动物和风车。

原有七个「小小奇迹」与新徽章是两套独立收藏，原有玩法保持可用。开启右上角声音后，可听见柔和的对话提示音与收集音效。角色、图案与文字均为原创内容；对话采用离线分支脚本，不调用聊天服务或远程接口。

### 存档说明

徽章、聊天次数和第一次的选择保存在 `little-planet-neighbors-v1`；原景物收集继续使用 `little-planet-wonders-v1`，互不覆盖。浏览器允许本地存储时会自动保存。

**受限的嵌入式预览可能禁止本地存储。** 此时游戏仍然可以完整游玩，界面会提示“仅保留本次进度”。下载 HTML，在现代浏览器中独立打开，可使用浏览器本地存档。不同浏览器、不同站点来源或不同本地文件路径的存档不一定互通。

### 新增源码模块

- `src/residents-data.js`：七位邻居的身份、初次与重复对话、选项、回忆和徽章配置。
- `src/resident-models.js`：原创低多边形角色与动作骨架，刚性部件采用顶点颜色合并。
- `src/resident-art.js`：头像和七枚手绘感 SVG 徽章。
- `src/neighbors.js`：聊天状态机、移动锁定、奖励防重复、徽章簿、邻居标记及存档。
- `src/neighbors.html`、`src/neighbors.css`：温暖纸张风格的对话与收藏界面，含移动端及键盘无障碍操作。

## V2 · 画面精修

本轮保持原有行走、跳跃、镜头切换和七处收集互动，主要调整视觉：

- 不规则岩壁、切面山体与不对称雪顶，替换规则圆锥山峰。
- 柔和地表法线、低对比度草地纹理和更清楚的海岸轮廓。
- 营地及农田的弯曲土路，以及花丛、蕨类、河岸植被。
- 木桶、柴堆、路牌、花窗、灯笼、炊具、小拖拉机与干草车。
- 更紧凑的云朵、冷色冰晶、风化沙岩与更疏朗的树林。
- 调整全景与近景构图，并使用柔和阴影；设备不支持浮点渲染时回退到 PCF 阴影。
- 使用逐实例颜色合批，降低丰富场景细节带来的绘制开销。

沿用原有收集存档格式。`src/art.js` 负责模型精修，`src/scenery.js` 负责土路、海岸和场景道具。

## 直接游玩

双击 `index.html` 即可打开。所有脚本、材质与图形资源均已内嵌，无需联网或启动服务器。需要支持 WebGL 2 的现代浏览器。

也提供完全相同的独立文件 `little-planet-v3.html` 和 `little-planet.html`。

### 操作

- **W A S D / 方向键**：在球面上行走
- **Shift + 移动**：奔跑
- **空格**：跳跃
- **E**：与附近的邻居聊天，或与景物互动
- **F**：附近有两种互动时，执行另一项
- **B**：打开邻居与友谊徽章簿
- **U**：切换星球全景与旅人近景
- **C**：将视角移回角色
- **M**：打开探索手记
- **点击地面**：自动走向目标
- **拖拽 / 滚轮**：环绕 / 缩放
- **触屏**：点击地面或使用虚拟摇杆；双指缩放；右侧按钮跳跃和切换视角

顶端的探索手记提供七个区域的快速旅行。到达后靠近微光并按 E，收集各地的小小奇迹。收集进度在浏览器允许本地存储时自动保存；受限的嵌入式预览中会使用当前会话进度。

## 世界

1. **Fernwood / 蕨木森林** — 木屋、松林、河流、木桥和篝火营地。
2. **Sunmeadow / 晴风草甸** — 风车、农田、羊群与红顶农舍。
3. **Frostfall / 霜落雪原** — 冰晶、雪松和冰屋。
4. **Amber Dunes / 琥珀沙丘** — 沙岩遗迹、仙人掌和日晷。
5. **Tidehaven / 潮汐海岸** — 棕榈、木栈桥、帆船和海螺。
6. **Ember Heights / 余烬高地** — 熔岩、烟雾、营帐与沉睡的火山。
7. **Skyreach / 云端遗迹** — 石拱门、山地与望远镜。

声音默认关闭，点击右上角扬声器开启。环境风声、鸟鸣与收集音效均由 Web Audio 合成，不依赖外部音频。

## 编辑与构建

```bash
npm install
npm run build
npm start
```

开发服务器监听 `0.0.0.0:8080`。

- `src/models.js`：低多边形模型、角色、动物及局部动画。
- `src/art.js`：岩壁、树木、建筑及小道具的视觉精修。
- `src/scenery.js`：弯曲土路、海岸、植被与生活化细节。
- `src/world.js`：球面地形、生物群系、区域布置、河流、道路与实例化批处理。
- `src/main.js`：移动、跳跃、相机、自动寻路、交互、进度存储、音效与触控。
- `src/page.html`、`src/style.css`：界面与响应式样式。
- `bundle.mjs`：打包 Three.js 并生成完全独立的 HTML。

修改后重新运行 `npm run build`。此 GitHub 仓库构建后输出根目录的 `index.html`。推送更新后的 `index.html` 到 `main` 分支即可自动重新部署 GitHub Pages。

## 技术

Three.js r170、OrbitControls、实例化静态几何体、缓存软阴影、球面切线移动、四元数方向与相机过渡。没有运行时网络请求、外部图片或远程字体。
